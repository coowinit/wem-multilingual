## 7. 核心测试

### T01 默认语言

```text
/about-us/
```

正常显示英文。

### T02 Spanish Prefix

```text
/es/sobre-nosotros/
```

能够解析到同一个 WordPress Page Object。

### T03 Title Overlay

Source：

```text
About Us
```

Spanish：

```text
Sobre nosotros
```

Spanish URL 输出西班牙语标题。

### T04 Source Clean

数据库原始：

```text
post_title
```

仍然是：

```text
About Us
```

### T05 Canonical

Spanish：

```text
canonical
→ /es/sobre-nosotros/
```

### T06 hreflang

输出：

```text
en
es
x-default
```

### T07 Draft Language

Spanish 状态：

```text
draft
```

则不应作为正式语言版本暴露给 SEO。

### T08 Published Language

Spanish：

```text
published
```

正式允许访问并输出 SEO 信号。

### T09 Disable Safety

停用插件：

```text
/about-us/
```

继续正常。

原始内容不受影响。

### T10 Cache Isolation

```text
/about-us/
```

与：

```text
/es/sobre-nosotros/
```

不能缓存串语言。

## 10. 开发原则

每增加一个能力，都先问：

```text
它属于 Core？
还是 Adapter？
```

如果属于 Adapter：

```text
不要污染 Core。
```

如果某项功能需要大量特殊兼容：

```text
先建 Lab
再决定是否合入正式架构。
```
