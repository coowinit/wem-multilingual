# 07. v0.1.0 Experimental Core 开发规划

> 目标：用最少代码验证 WEM Multilingual 的核心架构是否成立。
>
> **最终状态：Experimental Core 已完成实现与 T01–T10 验收。**

---

## 1. v0.1.0 不是产品版

v0.1.0 的目标不是做完整多语言产品，而是验证：

```text
Single Source
+
Native Routing
+
Slug Overlay
+
Translation Repository
+
Object Language State
+
Structured Overlay
+
SEO
+
Disable Safety
+
Basic Cache Isolation
```

最终实验结论：

> **上述 Core 组合在当前 English + Spanish、Page / Post、post_title 范围内成立。**

仍然不代表插件已经适合直接用于生产站。

v0.1.0 最终采用 4 张独立数据表：

### Source Units

```text

```

```text

```

### Translations

```text

```

负责：

```text

```

### Object Language State

```text
wp_wem_ml_object_state
```

负责：

```text
object_type
object_id
language
status = draft | published
```

### Object Slugs

```text
wp_wem_ml_object_slugs
```

负责：

```text

object_id
language

```

最终确认的边界：

```text
Translation ≠ Publication State
Translation ≠ Route Slug
```

三类职责保持独立。

## 8. 核心测试结果

### T01 默认语言 — ✅ PASS

默认语言 URL 正常访问，Source Object 不受多语言逻辑影响。

### T02 Spanish Prefix — ✅ PASS

`/es/.../` 可通过 WordPress Native Rewrite + Query Vars 进入目标语言上下文。

### T03 Translated Slug / Title Overlay — ✅ PASS

Translated Slug 可解析到同一个 WordPress Object；Published + Current 时运行时显示 Spanish Title。

### T04 Source Clean — ✅ PASS

`wp_posts.post_title` 始终保持 English Source，不写回 Spanish Translation。

### T05 Stale Detection — ✅ PASS

通过：

```text
Context = Identity
Hash = Version
```

实现 Source Drift / Stale 检测。

### T06 SEO Signals — ✅ PASS

Published 状态验证通过：

```text
self canonical
hreflang=en
hreflang=es
hreflang=x-default
html lang
```

### T07 Draft Language — ✅ PASS

Spanish = draft 时：

```text
Spanish URL → 404
Title Overlay → not-published
Spanish canonical → not public
Source 页面不输出 Spanish hreflang
```

### T08 Published Language — ✅ PASS

Spanish = published 时：

```text
Spanish URL → 200
Route → resolved
Title Overlay → applied
SEO Spanish Public → true
```

### T09 Disable Safety — ✅ PASS

停用插件后：

```text
Source URL → 继续正常
Source Data → 不变化
WEM Tables → 保留
Spanish WEM Route → 消失
```

重新启用后 Slug / Translation / State 自动恢复。

测试期间发现并修复：

> 仅调用 `flush_rewrite_rules()` 不足以保证停用时移除已经注册的 WEM Rewrite Rule。

最终方案：

```text
显式移除 WEM Rewrite Rule
↓
再 flush_rewrite_rules()
```

### T10 Basic Cache Isolation — ✅ PASS

匿名无痕环境中交替访问：

```text
English → Spanish → English → Spanish
Spanish → English → Spanish → English
```

Title / html lang / canonical 均未串语言。

当前 Cloudflare HTML 响应观察为：

```text
CF-Cache-Status: DYNAMIC
```

因此本轮结论是：

> **Basic Cache Isolation 通过；尚未验证 Cloudflare edge HTML HIT / Cache Everything 场景。**

## 12. 开发原则

每增加一个能力，都先问：

```text
它属于 Core？
还是 Adapter？
还是 Lab？
```

如果属于 Adapter：

```text
不要污染 Core。
```

如果某项功能需要大量特殊兼容：

```text
先建 Lab
再决定是否合入正式架构。
```

---

## 13. 最终结论

v0.1.0 给出的答案是：

> **在当前实验边界内，Single Source + Local Translation Repository + Native Routing + Publication State + Runtime Overlay + SEO Core 的组合是可行的。**

下一阶段不应继续扩大 Core，而应开始：

```text
v0.1.1
Elementor Structured Translation Lab
```
